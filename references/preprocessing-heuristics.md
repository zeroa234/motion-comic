# 静态漫画解析、源头直出与二次精修工程（L0 通用方法论）

L0 的核心职责是将任意来源的漫画/分镜视觉素材转化为**统一、清洁、可供 L2 合成器消费的标准资产包（`manifest.json` + 分格资产）**。

**关键前提**：并非所有项目都要跑一遍“分格检测 → 抠气泡 → 去字修补”的逆向流水线。逆向拆层只是针对“已合层成品漫画”的补救手段；如果是**自己手绘、本地 AI 从零生成，或对原作做了大幅度二次编辑/精修**，应从源头省去多余的逆向步骤，直接产出更干净的分层与关键帧。

---

## 0. 三种素材源模式与 L0 步骤剪裁矩阵

| 环节 | **Mode A：现成漫画原页改编**（已合层成稿） | **Mode B：原创手绘 / 本地 AI 从零生成**（源头直出） | **Mode C：原作漫画大幅二次编辑 / 重构**（深度二创精修） |
|---|---|---|---|
| **条件超分** | 必要（扫描/低分原页 `< 1600px` 触发） | **可跳过**（源头直接按目标高清分辨率绘制/生图） | **按需**（先超分/扩图精修，回灌后不再重跑） |
| **分格检测与阅读序排序** | 必要（自动检测 + `panels_override` 兜底） | **跳过**（直接按单镜/单格独立出图，1 图 = 1 panel） | **可跳过或仅作粗裁底稿**（重排/重切后按单格回灌） |
| **UI / 聊天屏自动保护** | 必要（防误擦内嵌聊天气泡与界面） | **跳过**（UI 界面单独作为透明层或直接出 `use_orig` 图） | **按需**（精修后直接标记 `use_orig` 或独立叠加） |
| **气泡抠层与去字修补** | 必要（逆向抠气泡 + 单次羽化局部修补） | **跳过**（源头生成纯净无字图，**严禁先画字再擦字**） | **跳过二次自动去字**（改用人工/AI 精修重绘遮挡区，避免自动化修补破坏精修细节） |
| **气泡呈现方式** | `cue_sync` 弹出原气泡，或删减冲突时按格屏蔽 | **正向叠加**（手绘导出透明气泡层 / 矢量程序化气泡）或纯字幕（`bubble_mode: "hide"`） | **正向重排气泡或纯字幕**（彻底消除原漫对白与二创剧本的文字冲突） |
| **前背景拆层（多层视差）** | 黑白漫默认跳过，全彩漫事后抠图 | **源头直出**（手绘直接导 `fg.png`+`bg.png`；AI 可分层生成完整背景），视差大位移无拉丝 | **精修期主动拆层与补底**（针对核心大运镜镜头手工/AI 补全被遮挡背景） |
| **深度估计（`depth16.png`）** | 必要（供 `fast_25d` 使用） | 走 2.5D 镜头需补算（或直接复用生图期的 Depth 图）；**纯 `video_clip` 镜头可填中性平深度跳过推理** | 精修完成后对最终 `clean.png` 统一重算 16-bit 深度（切勿复用二编前旧深度图） |
| **首尾双关键帧（FL2V）** | 仅相邻分格过渡时天然具备 | **天然优势**：直接按分镜生成“起势帧 + 收势帧”两张纯净图送 FL2V，大幅降低动态不可控度 | **高杠杆玩法**：基于原作单格做图生图/局部编辑产出状态 B 尾帧，解锁异帧 FL2V 演出 |

### Mode B（原创手绘 / 本地 AI 从零生成）源头最佳实践
1. **带运镜余量出图（Overscan / Bleed）**：原生画幅建议比 L2 目标视口大 `15%–25%`（或四周留安全构图边距），2.5D 视差晃动与镜头推拉时彻底告别边缘裁切与边缘拉伸伪影。
2. **彻底分离“画面层”与“文字/气泡层”**：
   - 本地 AI 生图提示词显式约束 `no text, no speech bubble, no watermark, clean artwork`，产出的图像直接就是最高质量的 `clean.png`；
   - 需要漫画气泡风时，在 L2 用独立透明气泡 PNG 或矢量样式模板配合 `timeline.json` 正向弹出，字号、语言和排版完全可控，无需迁就原图位置。
3. **直接对齐导演清单**：每镜出图命名即对应 `<scene>/<panel_id>/clean.png`，用轻量脚本写入 `manifest.json`（`bubbles: []` 或指向正向气泡 PNG，`orig.png` 可与 `clean.png` 同源），即可零摩擦接入 L1 `story`、L2 双轨合成与 L3 质检。

### Mode C（原作漫画大幅二次编辑 / 重构）推荐工作流
当计划投入精力对原作做深度二创（如大幅删改剧情、重绘被大气泡遮住的关键部位、扩图改竖屏/横屏比例、黑白漫精修上色、拆层补背景、或二编出动作首尾帧）时，建议采用**“先借 L0 粗拆 → 脱离自动化做精修 → 按 Mode B 纯净单格回灌”**的三段式：
1. **借壳起稿（可选）**：仅对需要参考原作的页跑一次 L0 分格裁剪（或粗去字），把需要大改的分格挑出来作为二编底稿；不需要改动的普通对话格直接沿用 Mode A 产物，**不必全片一刀切重画**。
2. **精修与重构（编辑域）**：
   - **扩图（Outpainting）**：把原作窄横格/斜格向四周扩充至适配目标画布，消除大面积黑边或强行裁头截脚；
   - **重绘遮挡与改画**：用画图软件或本地图像编辑模型彻底重绘大气泡/网点覆盖区域，质量远超纯自动化 Inpainting；
   - **风格迁移 / 上色**：若将黑白原漫改为全彩，务必同步将 L0 `manifest.json` 的 `is_monochrome` 更新为 `false`，并在 L1/L2 切至全彩参数（禁用平涂 LoRA、`video_desaturate: 0.0`、换 `watercolor_gloss` 等彩色流体风格）；
   - **构造双关键帧**：对原作极具张力的单格，二编出一张连续动作的尾帧图（`clean_end.png`），L1/L2 直接走异帧 FL2V（`--last-image` + `stretch`）实现可控演出。
3. **锁定回灌（严禁被自动化覆盖）**：
   - 将精修后的最终单格写回 `panels/<pid>/clean.png` 并刷新 `content_hash` 与 `depth16.png`；
   - 在 `manifest.json` 标记该格来自手工/二编精修（如 `panel_source: "edited"`），后续批次增量跑 L0 时务必加 `--skip-existing` 或隔离精修目录，**防止自动化去字重跑覆盖精修稿**。

## 1. Mode A 现成原页逆向拆层标准流水线（按执行顺序）

1. **输入归一化与条件超分**：
   - 自动检测原图宽度，低于工作阈值（如 `< 1600px`）时触发保真 2× 动漫超分；已高分辨率原图直接跳过，避免二次锐化破坏网点。
   - 记录输入文件 SHA256 短哈希，输入未变且已有 `manifest.json` 时跳过重算（`--skip-existing`）。
2. **色彩属性与特殊页面识别**：
   - **黑白/全彩判定**：计算像素通道极差均值（`mean(max(R,G,B) - min(R,G,B))`），低于阈值判为黑白页；该标志同时透传给去字、拆层与 L2 渲染/AI 增强（决定是否单色锁色、是否挂赛璐珞风格约束）。
   - **全屏 UI / 手机聊天记录页判定**：对特定高频 UI 特征（如大片蓝灰聊天背景、固定消息布局）自动标记 `is_chat_page = true`。
   - **聊天页快速短路策略**：一旦判定为 `is_chat_page`，**直接跳过擦字、前背景拆层与深度网络推理**，直出 `orig.png` 与中性平深度图（中值填充），并在 L1 自动锁定 `use_orig=true`、`fit="contain"`、零视差、零呼吸抖动——既提速又彻底杜绝截屏文字被抹糊或边缘裁切。
3. **分格检测与阅读序排序**：
   - 使用检测模型提取分格矩形，同时必须提供**手工分格覆写接口（`panels_override`）**应对跨页破格、异形斜切或无边框构图。
   - **阅读序聚类算法**：日漫按“从上到下分行（行垂直重叠聚类），行内从右到左”；美漫/条漫按“从上到下、行内从左到右”。不要只按中心点 `y` 简单排序，否则上下高低错落格会乱序。
   - **分格内气泡局部排序**：每个分格收集交并覆盖率达标（如 `inter / bubble_area >= 0.35`）的气泡，在分格局部坐标内再次按阅读序重排，确保后续气泡随台词弹出顺畅。
4. **UI 白名单保护与气泡抠层**：
   - **三级防误擦保护**：
     1. 自动规则保护混合页内的嵌入 UI（绿色/彩色聊天气泡、蓝灰底横向消息栏、照片内便利贴）；
     2. 显式归一化白名单框（`keep_boxes`），命中中心或高 IoU 即跳过擦除（保护通话窗、视频预览条、状态栏）；
     3. 仍允许通过显式开关关闭自动保护以应对极少数误判。
   - **气泡独立抠层（边界感知 + 防吞杂物铁律）**：
     - 兼容**白底气泡**与**暗底/反白气泡**，导出带透明通道的独立 PNG；
     - **严禁使用大核形态学闭运算（如 `MORPH_CLOSE` > 15px）或粗暴矩形/椭圆回退**：黑白漫背景同为白色，大核闭运算会直接跨过 2–4px 的气泡黑描边，把气泡外的头发、速度线、分格边框与相邻气泡吞入气泡图层，在 L2 弹出/视差时带出明显杂物；
     - **正确做法（页面级拓扑抠层）**：对轮廓墙仅做极细 `3×3` 封缝，从 `bbox` 中心区出发提取主连通域，对**物理上无分隔黑线、共享同一内部连通域的连体葫芦气泡**自动合并（避免相邻半截字被切裂），吸收紧贴内缘的字内小封闭环并经外轮廓实心填洞（防粗体贴边汉字内部镂空），最后仅外扩 3–5px 精准包入气泡自身描边。
5. **局部修补去字（Inpainting）四大防伪影铁律**：
   - **局部裁块而非整页修补**：只对含文字/气泡的局部扩展 ROI 做修补，保留未遮挡区域 100% 原画质。
   - **像素级去重（单次羽化）**：先将同页内所有待擦掩码合并，确保每个像素**最多只修补一次**，严禁气泡框与文字框重叠导致二次修补产生严重糊斑。
   - **黑白页强制单色化**：修补模型输出在黑白页极易带入偏绿/偏紫彩噪，必须在贴回前强制转单通道灰度回写 RGB。
   - **无框自由字（旁白/拟声字）防渗白**：若开启擦除无框自由字，严禁直接用矩形大框送修补（白页边外扩极易把背景灰浆渗入留白区），必须使用**笔画级紧致掩码提取**，仅精准覆盖文字墨迹笔画本身。
6. **16-bit 深度估计与可选拆层**：
   - 深度图必须以 **16-bit PNG** 落盘；8-bit 深度在 GPU 视差位移时会产生明显的同心圆带状撕裂。
   - 黑白网点漫默认单层 2.5D（背景与人物网点混杂，硬抠前景常出毛边）；全彩页可按需开启前背景拆层增强视差层次。

## 2. 资源与显存治理经验

- **低显存/分阶段卸载**：单卡跑完超分、分格、气泡、去字、深度 5 个模型时，每阶段结束支持显式释放权重并清空显存缓存，防止后半段 OOM。
- **默认不落盘冗余调试大图**：页级全尺寸中间图与 8-bit 预览深度图仅在显式开启调试选项时保存，默认仅保留 `orig.png`、`clean.png`、`depth16.png`、气泡 PNG 与 `manifest.json`，避免长篇漫画轻松产生数 GB 垃圾缓存。
- **强制生成调试拼图（Debug Sheet）**：每页保存一张轻量可视化总览（叠加分格框、编号、气泡框与去字前后对比），便于在进入 L1 编排前 1 分钟内肉眼扫完一整话的 L0 质量。
