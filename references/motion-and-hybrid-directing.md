# 动态导演与双轨混合选型（L1/L2 通用方法论）

本规范定义如何将静态分层漫画演活，重点解决**成本与画质平衡、黑白与全彩画风保真、AI 视频防穿帮选型、以及 2.5D 物理形变与粒子的协同**。

---

## 1. 双轨生产策略（核心工程模型）

永远不要把整部 10–20 分钟的动态漫画全部交给 AI 视频模型硬生：算力爆炸、风格漂移、口型与画面细节崩溃难以全量可控。应坚持**双轨并行**：

1. **轨 A：快产纯 2.5D 轨（Fast Baseline，零 AI 视频）**
   - 全片使用 GPU 2.5D 视差 + 局部弹性形变 + 镜头推拉 + 气泡弹性弹出 + 粒子/氛围特效；
   - **价值**：100% 保留原作者线条、笔触、网点与色彩；几分钟全片可在数十秒内出片；适合快速验证对轴节奏、批量分集交付、以及作为混合轨的兜底 `fallback`。
2. **轨 B：精细化混合轨（Selective Hybrid）**
   - 在完全对齐并通过 L3 质检的快产分镜上，仅将 **10%–25% 最具视觉回报的核心镜头**（强动态往复、高潮爆发、液体/烟雾/飘动特写、情绪高光）覆写为 `renderer: "video_clip"` + `fallback: "fast_25d"`；
   - **稳定键绑定铁律**：在 `enhanced-spec.json` 中优先用 `"page:panel"`（如 `"012:p02"`）绑定增强槽位，而不是易随增删镜变化的 `"s18_..."` 序号；
   - **同格多子镜自动续接**：若同一分格在 L1 被拆成多个连续子镜且共享同一支 AI 片段，编译器自动按子镜时长分配 `video_time_offset` 或比例 `video_trim`，避免切子镜时视频突然回跳第 0 帧。

## 2. 画风分化准则（黑白网点漫 vs 全彩/水彩漫）

两类漫画在 AI 增强、后处理调色与粒子风格上存在本质冲突，严禁混用同一套默认参数：

| 维度 | 黑白日漫 / 网点漫画 | 全彩 / 水彩 / 赛璐珞彩漫 |
|---|---|---|
| **AI 视频风格 LoRA** | 可挂载扁平动漫/线条强化 LoRA，稳定黑白线条与网点 | **务必禁用强平涂/扁平风格 LoRA**，避免抹平手部结构与水彩渐变层次 |
| **色彩后处理** | 强制去饱和（`video_desaturate: 1.0`）+ 轻度锐化（如 `0.15`），彻底消除 AI 视频带来的彩噪与灰黄偏色 | 锁定原色（`video_desaturate: 0.0`），提示词显式约束保持原画色板（如 warm watercolor palette） |
| **流体/粒子风格** | 高对比度重描边漫画墨水风（`manga_ink`） | 半透明高光水彩/液态风（`watercolor_gloss` / `translucent_water`） |
| **L0 前背景拆层** | 默认关闭（网点边缘易碎），走单层深度 2.5D | 可按需开启拆层增强景深层次 |

## 3. AI 视频生成选型矩阵（按动作拓扑而非盲选模型）

无论底层是哪一代 I2V / FL2V 视频模型，按动作物理规律分为三类：

| 镜头动作拓扑 | 推荐生成模式 | 渲染播放模式 | 严禁踩的坑 |
|---|---|---|---|
| **周期往复动作**（呼吸起伏、节奏摆动、重复循环动作） | **首尾同帧闭环（FL2V：首帧 = 尾帧）** | `seamless_loop`（周期取 `N - 1` 帧跳过重合末帧） | 避免只用单首帧导致后半段姿态漂移，或 `xfade_loop` 产生溶图重影 |
| **相邻两格平滑变身/过渡** | **异帧首尾插值（FL2V：首帧 = 格 A，尾帧 = 格 B）** | `stretch`（GPU 亚帧线性插值平滑铺满镜头时长） | 勿用循环模式导致跳回格 A |
| **单向爆发 / 液体喷涌 / 泪水滴落 / 烟雾扩散 / 不可逆状态变化** | **单首帧（I2V）** | - `< 5s` 一次性收尾定格：`clamp`<br>- `5–8s` 中短单向动作：`stretch`（跨子镜配 `video_trim`）<br>- `> 8s` 持续单向/流体：`xfade_loop`（尾段短交叉溶图限幅回首） | **① 严禁首尾同帧**：锁回未爆发尾帧会迫使模型抑制动作幅度或凭空擦除液体/烟雾；<br>**② 严禁 `clamp` 用于长周期镜头**（后半程冻帧）；<br>**③ 严禁 `pingpong` 用于含滴落/飞溅/流泪/烟雾的镜头**（重力倒放穿帮） |

| **说话特写 / 精准对口型镜头** | **单首帧 + 真实音频时间轴锚定（I2V + Audio Guide）**，按该镜真实时长向上取整一次生成 | **`clamp`（严格 1:1 原速正放，不循环、不变速）** | **① 严禁对音频驱动镜头使用 `stretch`**（变速缩放会令口型整体错位）；<br>**② 无音频输入的 I2V/FL2V 镜头严禁在提示词中要求角色自由张嘴说话**（否则出现“没出声嘴乱动”违和感，应锁死原嘴型只动眼神/发丝/呼吸/特效）；<br>**③ 稳定优先选首帧+音频锚定，仅在需要大幅改构图自由演出时考虑 Reference-to-Video 参考线路** |

### 分辨率预算与评测原则
- 优先选择兼顾画布锐度、暗部静态无闪烁与高动态稳定的甜点像素预算（再配合 VSR 等 2× 超分对齐目标竖屏/横屏画布）。
- 更换视频模型或采样参数做 A/B 评测时，**测试集必须同时包含“偏静态微动特写”与“高动态复杂动作”两类样本**，防止只测静态而误以为动态稳，或只测动态而忽略暗部噪点闪烁。
- 若项目使用独立配音母带，视频生成链路默认跳过无用音频解码以省显存与耗时（且缓存键需包含该开关）。

## 4. 2.5D 深度视差、局部形变（`zones`）与粒子防冲突

### 2.5D 深度视差与局部弹簧形变
- **微分同胚位移**：2.5D 深度视差与局部椭圆 `zones` 形变应保持平滑连续衰减，避免图像撕裂。
- **按部位区分物理特性**：
  - **面部/头部区域（`face`）**：必须配置较高的刚性平台系数（如 `plateau ≈ 0.62`）以防五官扭曲变形，且**默认禁止高频微颤（`shiver`）**，颤抖仅在明确剧情需要时显式开启；
  - **弹性/呼吸区域**：省略幅度键时按驱动器类型自动补齐默认温和形变；若显式将所有幅度设为 0，L1/L3 应发出 `noop_zones` 告警。
- **各向同性补偿**：竖屏或非正方形画布中，所有局部椭圆形变与粒子旋转前必须传入画布宽高比（`aspect`）做各向同性补偿，防止圆形/液滴被拉扁成方块。

### 粒子与 AI 视频防冲突
- 当镜头切换为 `video_clip` 时，合成器**默认抑制 2D 流体粒子叠加**（避免粗颗粒 2D 粒子遮挡 AI 已生成的自然动态），仅在显式配置 `allow_fluid_on_video: true` 时放行。
- 跨镜头转场期间，若源镜头仍在播放流体粒子，粒子应归属源镜头坐标投影，防止转场瞬间粒子漂移到新画格错位位置。
- 所有喷射口（`burst_anchor`）与慢滴点（`drip`）严禁凭感觉盲填归一化坐标，必须对照网格与 L3 `zones_overlay` 标定图精确校准；非喷射类音效（如拍击、碰撞）禁止挂接喷射锚点。

## 5. 渲染器工程鲁棒性底线

- **2× 超采样抗锯齿（SSAA）**：细线条漫画缩放推拉极易出现摩尔纹与像素抖动，必须以 2× 工作分辨率渲染后再高质量下采样至目标分辨率。
- **滑窗资源管理**：长篇多镜头（数十至上百镜）必须按当前播放窗口预载前后数镜并及时释放远镜纹理、解码帧与气泡缓存，严禁一次性常驻全部素材导致显存/内存爆炸。
- **防死锁异步编码**：帧数据经管道喂给编码器时，必须异步排空 `stderr` 或分线程读写，防止管道缓冲区满导致长视频渲染中途卡死。
- **跨环境无头硬件加速**：优先本机 GPU 渲染 + 硬件编码；若无头环境（远程桌面/断连虚拟屏）导致图形上下文回退软渲染，应支持无缝切换至无头 EGL 硬件后端，并显式指定字体目录保证硬字幕中/日/英字体渲染一致。
- **并行字幕不截断**：多角色同时说话（`∥` 并行对白）时，硬字幕轨道需支持上下分行叠加显示而非后句截断前句。
