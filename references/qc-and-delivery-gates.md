# 质检门禁、可视化标定与版本交付规范（L3 通用方法论）

任何动态漫画成片在交付给用户之前，必须同时通过**自动化硬门禁**与**可视化抽检审计**；未过门禁的版本不得视为可交付成果。

---

## 1. 自动化硬门禁（任一失败即退出码非零，阻断交付）

| 检查项 | 判定标准 | 典型故障根因 |
|---|---|---|
| **契约静态校验** | `validate_story` 零硬错；无非单调时间/非正时长 | `page-map` 锚点顺序写反、音频重混后两行顺序颠倒 |
| **时长一致性** | `|actual_dur - expected_dur| <= 0.25s` | 编码截断、FPS 配置不匹配、尾帧丢失 |
| **音轨与音画同步** | 存在有效音轨，且 `|audio_dur - video_dur| <= 0.35s` | 混音截断、封装流拷贝丢音频、窗口裁剪越界 |
| **三点黑帧抽检** | 每个镜头在 `start` / `mid` / `end` 三点采样均值不得 `< 5.0`（排除全片首帧淡入与末帧淡出） | 纹理加载失败、视频解码 EOF 冻黑、转场参数溢出 |
| **零隐性降级** | `render_meta.json` 中 `fallback_count == 0` | AI 片段路径拼错、文件未生成却静默退回 2.5D |
| **无空壳形变** | 检查 `noop_zones` 列表为空（或在报告中明确核销） | `zones` 坐标写了但把所有形变幅度覆盖成 0 |

## 2. 可视化标定与肉眼审计清单

自动化全绿不代表视觉无穿帮，必须导出两类拼图并快速肉眼审计：

### 2.1 `zones_overlay.jpg`（局部形变与粒子标定图）
- 在 `clean.png` 上叠加每个镜头的：
  - 内圈（1× 半径）与外圈（1.65× 衰减范围）椭圆 + 十字中心 + 枢轴点；
  - `burst_anchor` 喷射原点与方向箭头；
  - `drip` 慢滴锚点标记；
  - 无效空壳区高亮标红 `[NO-OP]`。
- **审计要点**：面部圈是否盖住五官边缘外泄、呼吸/弹性圈是否偏移主体、喷射/滴落锚点是否严丝合缝对准画面实际源头。

### 2.2 `qc_sheet.jpg`（全片中点抽帧总览表）
- 自动截取每个镜头中点帧，顶部标注 `shot_id [renderer] @time`。
- **审计要点**：
  1. **聊天屏/手机界面页**：确认文字清晰未被擦糊、画面 `contain` 无裁边；
  2. **去字与气泡**：无明显糊斑、无白边自由字渗灰、无删减后残留的矛盾原气泡；
  3. **硬字幕与气泡布局**：底部硬字幕清晰、字体无缺字方块、不严重遮挡核心画面；
  4. **混合 AI 镜头画风一致性**：黑白漫无偏色、全彩水彩漫色温与邻镜一致无塑料感。

### 2.3 动态重点抽看（针对 AI 混合镜头与高潮段）
- **循环接缝**：检查 `seamless_loop` 与 `xfade_loop` 在周期交界处有无顿挫或明显鬼影；
- **重力方向**：确认所有液体/泪滴/烟雾镜头均为正放，无 `pingpong` 倒放；
- **子镜续接**：确认同格多子镜复用同一 `video_clip` 时连贯接续，未跳回首帧；
- **关键节点对轴**：抽听高潮音效与情绪转折点是否精准落在目标分格内。

## 3. 版本管理与交付纪律

1. **版本号不可覆写**：每次迭代产出必须带递增版本号（如 `v1`、`v2`、`v2.2`），**严禁覆盖用户尚未审看或已确认为当前最佳的成品**。
2. **双轨成对交付（推荐）**：当需要人工权衡原画保真与 AI 动态感时，成对交付同版本快产版（`*-fast25d.mp4`）、混合版（`*-hybrid.mp4`）与配套字幕（`.srt`），并汇报总时长、文件大小、AI 镜头数及 `qc_report` 核心指标。
3. **跨层沉淀**：修补单部作品的特定分格错位，只改作品目录内的 `page-map` / `panels_override` / `keep_boxes`；发现通用缺陷（如白边渗灰、默认颤抖、字幕截断），应沉淀回引擎公共层并同步更新本技能规范。
4. **阶段版本控制与磁盘清理**：每个里程碑用 git 记录文本配置与代码快照（大体积音视频与模型不入库）；确认新版本通过验收后再按需清理旧版大体积中间缓存。
